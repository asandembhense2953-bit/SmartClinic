════════════════════════════════════════════════════════════
DATABASE DESIGN — ENTITIES (3NF)
════════════════════════════════════════════════════════════

Entity          Primary Key        Key Relationships
------------------------------------------------------------
users           user_id (UUID)     —
patients        patient_id (TEXT)  —
doctors         doctor_id (UUID)   —
appointments    appointment_id     FK → patients, doctors

3NF Compliance:
- All attributes are atomic (1NF).
- No partial dependencies on composite keys (2NF).
- No transitive dependencies — every non-key attribute
  depends only on the primary key, not on another
  non-key attribute (3NF).
- Referential integrity enforced via FOREIGN KEY
  constraints with ON DELETE CASCADE.
