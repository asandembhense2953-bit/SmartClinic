CHALLENGES & HOW THEY WERE RESOLVED
════════════════════════════════════════════════════════════

Challenge 1: Rolling average with no data on first check-in
  On the first check-in of the day there are no completed
  consultations to average. Resolved by defaulting to 15
  minutes if the durations array is empty, with a visible
  flag (using_default: true) in the API response.

Challenge 2: Sensor 2 running before server is ready
  The setInterval started before the Supabase connection
  was confirmed, causing early errors. Resolved by calling
  occupancySensor.start() inside the app.listen() callback
  instead of at module load time.

Challenge 3: Double check-in prevention
  QR scan events could fire twice in quick succession.
  Resolved by adding a lockout flag in the frontend and
  a server-side check (getByAppointment) that returns 409
  if the patient is already in the active queue.

Challenge 4: BarcodeDetector API browser support
  The native BarcodeDetector API is not available in all
  browsers. Resolved by falling back to the jsQR library
  (canvas pixel-scan approach) when BarcodeDetector is
  unavailable.

Challenge 5: Prediction accuracy for very short consults
  When actual wait was much shorter than estimated, the
  accuracy score went negative. Resolved by clamping the
  result to a minimum of 0 in _calcAccuracy().


════════════════════════════════════════════════════════════
LESSONS LEARNED
════════════════════════════════════════════════════════════
- Breaking the sensor logic into a separate file
  (sensors/occupancySensor.js) made it easy to start/stop
  independently during testing without restarting the server.
- The shared api.js frontend layer (single source of truth
  for all HTTP calls) prevented duplicated fetch logic
  across all five dashboards.
- Real-time occupancy polling every 10 seconds via a
  CustomEvent on the document object was an effective way
  to update all dashboards without a page reload or
  WebSocket setup.
- Starting with the Postman collection open during
  development made it much easier to document endpoints
  as they were built rather than retrospectively.
